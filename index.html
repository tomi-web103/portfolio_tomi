04 / SELECTED WORKS

制作作品

Webデザイナー養成講座で制作した3つのWebサイトと、AI活用事例を紹介します。

WORK 01

NOOK.

BOOK CAFE / WEBSITE

※架空のブックカフェを想定した学習作品です。

担当：デザイン・実装。アイデアを整理する際の壁打ちにAIを活用しました。

本とコーヒーを楽しみながら、ひとりでゆっくり過ごせるブックカフェをイメージして制作しました。
30〜50代の女性を想定し、落ち着いた色合いや写真、余白を使って、ゆっくり見られる雰囲気になるよう意識しました。

POINT：配色・写真・余白をそろえ、サイト全体の雰囲気がまとまるようにしました。

WORK 02

ひびき眼科クリニック

EYE CLINIC / WEBSITE

※架空の眼科クリニックを想定した学習作品です。

担当：デザイン・実装。アイデアの壁打ちと画像生成にAIを活用しました。

地域の患者さんが、受診前に知りたい情報を分かりやすく確認できる眼科クリニックのサイトを制作しました。
診療内容や初診案内、子どもの受診など、必要な情報を探しやすくし、文字の読みやすさや安心感のある見た目を意識しました。

POINT：医療現場での経験を生かし、患者さんが「どこを見ればいいか」で迷わないよう、情報の分け方や見せ方を考えました。

WORK 03

Scentory

AROMA GUIDE / WEBSITE

担当：AIの支援を受けながら、デザイン・実装の両方を担当しました。

「今の気分や過ごしたい時間から、自分に合いそうな精油を探せるサイト」をテーマに制作しました。
アロマ初心者でも選びやすいように、SCENEから探す方法に加え、気分を入力しておすすめのSCENEや精油を表示する検索機能も作りました。
スマートフォンでも見やすいように表示を調整し、画像の軽量化やJavaScriptを使った動きなども取り入れています。

POINT：「精油の名前を知らなくても探せること」を意識し、使う人が選びやすい方法を考えながら改善しました。

AI SUPPORT / EXPERIMENTS

AIを使った試作・取り組み

これまでに、情報整理やデザインの言語化などを目的として、対話の流れや出力方法を考えたAIツールを試作しました。ここでは、その中から4つの取り組みを紹介します。

AI 01

クリニック申し送りBot

AI × 業務改善 / 医療

自由記述の申し送り内容を整理し、統一フォーマットと台帳転記用CSVへ変換する業務効率化プロトタイプです。

INPUT 自由記述の申し送り

PROCESS 内容整理・項目分類

OUTPUT 申し送りカード / CSV

POINT：入力方法を限定せず、普通の文章から必要な情報を整理できるよう設計しました。

※架空データを使用したプロトタイプです。

AI 02

mimosa

AI × DESIGN / HEARING

「なんとなくこんな感じが好き」という言葉にしにくい好みを、対話しながら整理するデザインイメージ整理AIです。

INPUT 色・ターゲット・雰囲気

PROCESS 段階的なヒアリング

OUTPUT デザイン方向・イメージ提案

POINT：一度に多くを聞かず、答えやすい順番で質問しながら好みを言語化します。

AI 03

Design Verbalization Trainer

AI × DESIGN / LEARNING

デザインの第一印象から、 色・文字・余白・レイアウトなどを分析し、 「なぜそう見えるのか」を言葉にする練習を支援します。

INPUT デザイン画像・第一印象

PROCESS 質問による段階的な分析

OUTPUT デザイン分析・改善視点

POINT：AIがすぐ答えを出さず、自分で考えながら分析できる質問の流れにしています。

AI 04

シャム猫秘書シアン

AI × PERSONALIZE / VERBALIZATION

対話しながら経験・価値観・得意なことなどを整理し、AIに自分を理解してもらうための「AI用トリセツ」を作成します。

INPUT 会話による回答

PROCESS 経験・価値観・希望を整理

OUTPUT AI用自己紹介・活用指示

POINT：1〜2問ずつ質問し、自分のことを説明するのが苦手でも答えやすい流れにしています。
